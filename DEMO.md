## Sample user journey (text)

1. **Sign in** → **Create room** or **Use template** (e.g. Study Group Setup).  
2. Open **My Learning Spaces** → enter a room → open the **learning journey** view and move through **steps**; open a **chat** for a step.  
3. Exchange messages; use **milestones / notes** when they appear.  
4. Adjust **Tone & Length**; compare AI behavior.  
5. **Share pins** (if applicable) → start a **pin-seeded** chat.  
6. **Generate document** / export notes or an outline.  
7. Start a **new chat** in the same room and check whether **welcome / context** reflects prior work.
